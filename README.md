# 🌸 Berlingieri Fiori

Sito web ufficiale di **Berlingieri Fiori** — un'esperienza di acquisto online elegante e moderna per la vendita di fiori e composizioni floreali.

🌐 **Sito online:** [alelifedesign-coder.github.io/berlingieri-fiori](https://alelifedesign-coder.github.io/berlingieri-fiori/)

---

## ✨ Funzionalità

- 🛍️ **Catalogo prodotti** con foto, nome e prezzo
- 🛒 **Carrello** con gestione quantità e riepilogo ordine
- 📱 **Ordine via WhatsApp** — il cliente invia l'ordine direttamente su WhatsApp
- 🔐 **Area Amministratore** protetta da password per gestire i prodotti
- 📸 **Immagini prodotto** con visualizzazione in popup
- 📱 **Design responsive** ottimizzato per mobile e desktop

---

## 🛠️ Tecnologie utilizzate

- HTML5
- CSS3 (Vanilla)
- JavaScript (Vanilla)
- Google Fonts (Inter, Playfair Display)
- LocalStorage per la gestione del catalogo

---

## 🔐 Area Amministratore

L'area amministratore è accessibile dal footer del sito tramite il link **"Area Riservata"**.  
Permette di aggiungere, modificare ed eliminare prodotti dal catalogo.

---

berlingieri-fiori/
